# ⚡ Speed+ — Ultra Precision Speed Test & Operator Audit

Speed+ is an enterprise-grade, high-precision web-based network speed test and telecom SLA audit platform.

## 🚀 Key Features

- **⚡ 100% Precision Physical Wire-Rate**: Framing overhead compensation (+3.85%) to accurately match ISP advertised bandwidth rates.
- **📡 Automatic Network Operator Detection**: Instant identification of your active carrier (BSNL, Jio, Airtel, ACT, TIC Fibre, Tata Play, Vi).
- **📍 Precise GPS Location**: Automatic browser location permission prompt with reverse-geocoding for exact street, district, and PIN code.
- **🏎️ Multi-Style Speedometer**:
  - **⚡ Cyber Cockpit**: Sweeping laser needle + 36 segmented LED ticks.
  - **🚀 Quantum Halo**: Dual counter-rotating orbital particle rings.
  - **📊 Matrix VU Tower**: Stereo vertical LED spectrum equalizer towers.
- **🎯 ISP SLA Audit & Plan Matcher**: Benchmarks delivered bandwidth against subscribed speed tier.
- **📊 Bufferbloat & Loaded Latency**: Measures gaming jitter and latency under heavy buffer saturation.
- **📜 Verified Speed Certificate & CSV Export**: Export audit reports with 1-click summary sharing.

## 📦 Zero-Dependency Deployment

This application runs as a standalone static web application.

### Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your GitHub repository and click **"Deploy"**.

### Deploy to GitHub Pages
1. In your GitHub repository, go to **Settings** $\to$ **Pages**.
2. Under **Branch**, select `main` and root `/`, then click **Save**.
